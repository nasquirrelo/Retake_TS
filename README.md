# Прогнозирование продаж Corporación Favorita

Работа посвящена прогнозированию продаж товаров в магазинах сети Corporación Favorita на основе данных соревнования Kaggle **Favorita Grocery Sales Forecasting**.

Цель работы - построить прогноз unit_sales для большого количества временных рядов, определяемых парой «магазин- товар», на горизонте 16 дней.

## Постановка задачи

В качестве временного ряда рассматриваются продажи конкретного товара в конкретном магазине.

Горизонт прогнозирования составляет 16 дней. Для оценки моделей используется временное разбиение данных без случайного перемешивания.

Validation-период:

- начало прогноза: 2017-07-31;
- конец прогноза: 2017-08-15;
- история для построения признаков заканчивается 2017-07-30.

Для финальной модели CatBoost использовались несколько исторических точек начала прогнозирования (historical forecast origins).

## Метрики

Для оценки качества использовались две метрики:

- **MAE** — средняя абсолютная ошибка в исходной шкале продаж;
- **NWRMSLE** — нормализованная взвешенная среднеквадратичная логарифмическая ошибка с повышенным весом для скоропортящихся товаров.

Отрицательные значения `unit_sales`, соответствующие возвратам товаров, перед моделированием спроса заменялись на 0.

## Модели

В работе были рассмотрены:

- Naive;
- SeasonalNaive;
- AutoETS;
- AutoTheta;
- CatBoost;
- многослойный перцептрон (MLP).

Для CatBoost последовательно исследовалось влияние:

- логарифмирования целевой переменной;
- признака onpromotion;
- характеристик товаров и магазинов;
- весов скоропортящихся товаров;
- внешних признаков цены нефти и праздников;
- использования нескольких historical forecast origins.

## Основные результаты

| Модель | MAE | NWRMSLE |
|---|---:|---:|
| Naive | 5.2521 | 0.9414 |
| SeasonalNaive | 3.9672 | 0.8794 |
| CatBoost v1 | 3.5793 | 0.8209 |
| CatBoost v2 | 3.2099 | 0.6797 |
| CatBoost v3 | 3.1121 | 0.6563 |
| CatBoost v4 | 3.1118 | 0.6562 |
| CatBoost v5 | 3.1303 | 0.6570 |
| Final CatBoost v4 (3 origins) | **3.0010** | **0.6476** |
| MLP | 3.2134 | 0.6603 |

AutoETS и AutoTheta оценивались отдельно на фиксированной выборке из 5000 временных рядов из-за вычислительных ограничений, поэтому их результаты не включены в прямое сравнение с моделями, рассчитанными на полной validation-выборке.

Лучший результат на validation показала финальная модель CatBoost v4, обученная на трёх historical forecast origins.
